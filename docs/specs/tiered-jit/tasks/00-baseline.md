## Work

Keep `/notes/` entirely Git-ignored, with no allow-list exceptions. The
canonical specification set is `docs/specs/tiered-jit/`; the baseline and
performance protocol are generated in that same tracked directory. Local
notes and benchmark result bundles are not normative inputs.

Track this specification set. Add every final layout-only `repr(C)` schema named
by the layout catalog, all NativeFrame field/assembly offsets, the data-only
`HelperCatalogEntryV1`, boundary and memory-plan catalog row types, the
production key/newtype/enum schemas and the one shared StableEncode
implementation, then add
`tools/xtask/src/tiered_jit_baseline.rs` and expose exactly
`cargo run --locked --package nixe-xtask -- tiered-jit-baseline generate` and
`cargo run --locked --package nixe-xtask -- tiered-jit-baseline check`. They write/check
`docs/specs/tiered-jit/tiered-jit-baseline.toml` with the exact schema and source revision
specified in the [baseline contract](../baseline.md). Generate the complete sorted CoverageId inventory
directly from the decoder table, link every accepted memory/helper entry to its
one data-only memory/helper catalog declaration, add the required StableEncode
golden vectors and record every audited per-ISA lowering/helper/layout/bridge
bound. [Task 0](00-baseline.md) implements only the declarative MemoryEffectPlan/catalog schema
needed to produce the effect-table hash, not its guest decoder/execution
semantics, and does not implement runtime `HelperDescriptor`. CI must compare regenerated bytes, not merely parse
the file, and every accepted semantic/lowering source must contain its nearby
official Arm URL.

[Task 0](00-baseline.md) also implements the production, nonexecuting `tiered/layout.rs`
descriptors/calculator and every pure x86-64/AArch64 encoder used to establish
gateway, landing-pad, fallback, bridge, helper-island and cache-sync size
bounds. These are the same functions later called by publication; a second
xtask-only estimator is forbidden. [Task 1](01-abi.md) attaches semantic state maps and
runtime ownership and invokes those same emitters; it does not reimplement or
change their bytes/layout constants.
Thus the manifest freezes final structural bounds in [Task 0](00-baseline.md) rather than a
provisional number that [Task 1](01-abi.md) could reinterpret.

Because guest lowering is deliberately [Task 1](01-abi.md) work, [Task 0](00-baseline.md) generates one
synthetic CLIF fixture for every CoverageId directly from the declarative
catalog. A fixture contains only the minimal typed values, disconnected entry
shape, opaque Nixe statepoint/patch requests and worst-case live ranges needed
to exercise that CoverageId's fork hooks, allocator constraints and declared
reservation bound; it is not the instruction's decoder, semantics or production
lowering and no test may present it as such. [Task 0](00-baseline.md) freezes the fixture generator
and its CoverageId-to-request mapping. [Task 1](01-abi.md) replaces each fixture input with
the real decoder/lowering path and must reproduce or tighten, never exceed, the
same structural bound.

The feasibility harness must exercise both target encoders and prove that the
